# HT Vision Lab

独立的多人视觉理解实验项目，与 `HT-voice-lab` 解耦。

## 当前范围

首个里程碑只处理已有视频文件：

1. 为画面中的人脸建立会话内轨迹 `Face-01/02/03/04`；
2. 输出每条轨迹的时间范围、人脸框、置信度和可回看帧证据；
3. 判断各时间段中的活跃说话人；
4. 用 2～4 人视频统计漏检、轨迹换号和说话人判断错误。

视觉侧先独立验证，暂不绑定 `HT-voice-lab` 的 A/B/C/D，不建立跨会话真实身份，不接摄像头。

## 边界

- 输入：本地视频文件；
- 输出：待固定的 `visual_tracks.json`；
- 语音基线：`HT-voice-lab` 标签 `voice-baseline-2026-09-28`；
- 跨模态融合：等人脸轨迹和活跃说话人分别通过验收后实现。
